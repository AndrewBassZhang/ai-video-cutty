# Finder Media Preview 使用说明

Finder Media Preview 是一个适用于 macOS 13 或更高版本的本地媒体预览工具。它可以从 Finder 中快速打开视频、音频和照片，并提供快捷的定位、循环、音量和画面查看操作。

## 安装

1. 双击 `Finder-Media-Preview-macOS.dmg`。
2. 将窗口中的 **Finder Media Preview.app** 拖到 **Applications**（应用程序）图标。
3. 从“应用程序”启动 Finder Media Preview。

当前发行包使用 ad-hoc 签名，**没有 Developer ID 签名，也没有 Apple notarization（公证）**。首次打开时，macOS 可能阻止启动：请按住 Control 键点按应用，选择“打开”，然后在确认框中再次选择“打开”。这只需要做一次。

发行 DMG 采用标准“拖到应用程序”安装卷，并未强制设置 Finder 的图标位置（例如左侧应用、右侧 Applications）；这样不会改动您可见的 Finder 窗口状态。

## 从 Finder 快速启动

在 Finder 中选中一个媒体文件后，按 **⌘S** 可固定地启动 Finder Media Preview 并载入该文件。该快捷键是 Finder 启动入口；若其他软件占用了同一组合键，请先让 Finder 成为当前前台应用。

## 基本控制与默认快捷键

| 操作 | 默认快捷键 | 说明 |
| --- | --- | --- |
| 播放 / 暂停 | `Space` | 切换播放状态。 |
| 退出 | `⌘Q` | 退出应用。 |
| 前后定位 | `←` / `→` | 分别向后 / 向前跳转媒体总时长的 5%。 |
| 倒放 / 暂停 / 快放 | `J` / `K` / `L` | `J` 向后浏览，`K` 暂停或停止连续浏览，`L` 向前浏览。 |
| 设定 A / B 点 | `I` / `O` | `I` 记录 A 点，`O` 记录 B 点。 |
| 从头开始 | `R` 或“↶ 开头” | 回到媒体绝对开头并重新播放。 |
| 循环 | `P` 或“循环” | 开启或关闭循环；亮蓝色表示已开启。 |
| 清除 A/B | `X` 或“清除 A-B” | 移除已记录的 A/B 点，不改变循环开关。 |
| A/B 裁切导出 | “裁切导出…” | 视频和音频均需先安装 FFmpeg；视频可在保存前选择原始画幅、固定比例或自由框选；可先旋转/镜像预览，导出会继承该画面变换；生成新文件，原文件不会被改写。 |
| 导出音频 | “导出音频…” | 从视频或音频文件导出原始音频轨；没有有效 A/B 时导出整条音频，有效 A/B 时导出该范围。 |
| 音量 / 静音 | 竖向音量块 / `M` | 点击、拖动或在音量块上滚动；静音亮蓝色表示已开启，音量块会归零；取消静音会恢复此前音量。 |
| 重置画面缩放 | `0` | 将视频画面恢复为 1× 并回到中心。 |
| 全屏 | 窗口左上角绿色按钮 | 进入 macOS 原生全屏，占用一个独立桌面。 |

快捷键可在 **Settings（设置）** 中编辑。若您修改了某个快捷键，以设置页显示的配置为准。

## A/B 循环

用 `I` 记录 A 点、用 `O` 记录 B 点。A 点和 B 点构成有效区间时，开启循环会在该区间内反复播放，适合核对一小段动作、对白或音乐。

设置一个点后，时间轴会立即显示该点的标记。设置好 A、B 后，编辑遵循严格范围规则，避免标记交叉：在 A 左侧只能改 A；A、B 之间按 `I` 缩短左侧、按 `O` 缩短右侧；在 B 右侧只能改 B。无效或重合的范围不能导出。只设置一个点或清除了 A/B 点时，循环会回退为**整段文件循环**：从文件末尾回到开头继续播放。

## A/B 裁切导出

设好有效的 A、B 点后，右侧“裁切导出…”按钮才会启用。**视频和音频的 A/B 导出都依赖 FFmpeg。** 未安装时，应用会明确提示安装，不会假装已导出，也不会自动换用 macOS 原生编码器。

### 视频导出裁切编辑器

开始视频的“裁切导出…”后，在选择保存位置之前会先打开“导出画幅”编辑页；音频的 A/B 导出不会进入这个编辑页。默认选择是 **原始画幅（不裁切）**，会保留完整原始画面，不给 FFmpeg 添加画幅裁切。

编辑页只有**一行**比例按钮。默认“横向”时可选 **1:1**、**4:3**、**16:9**、**2.39:1（Cinema）** 和 **自由框选**；点同一行的“横向 / 纵向”切换后，三个非方形比例会立即变为 **3:4**、**9:16**、**1:2.39**，不会再出现第二行预设。切换时，正在使用的非方形固定比例会切换到对应方向，并尽量保留当前取景中心。原始画幅、1:1 和自由框选不受横/竖切换影响。

固定比例预设会先取得居中的最大可用画幅；之后只能拖动裁切框**内部**调整取景，名称和宽高比例保持锁定。只有明确切换到“自由框选”后，四个角才会出现并可拖动来调整宽和高；裁切框始终不会越出画面边界。

编辑页会实时显示当前模式和实际导出用的源像素宽、高与坐标。导出只会裁掉框外的画面，**不会缩放，也不会放大**裁切后的内容。由于 H.264 的 yuv420p 输出要求宽、高和 X/Y 坐标对齐为偶数，实际有效画幅与理想比例或拖拽位置可能相差 1 到 2 个像素；这属于编码色度对齐，并非额外缩放。

`2.39:1` 是当前常见的 Cinema Scope 宽银幕近似比例；较早的变形宽银幕常见写法是 `2.35:1`。本版本的 Cinema 预设固定为 **2.39:1**，不把它与旧的 2.35:1 预设混用。

### 旋转、镜像与裁切顺序

视频播放区左侧、竖向音量块右边有三个视频专属按钮：**“逆90°”**、**“顺90°”** 和 **“镜像”**。前两个按钮每次将当前预览旋转 90°；“镜像”切换左右镜像。点击后，播放画面会立即按当前状态显示，音频文件不会显示这些按钮。

这些操作只改变当前预览和新导出文件的画面，不会修改原视频文件的方向元数据或像素。之后进行视频 A/B 导出时，输出会继承当前旋转/镜像状态；处理顺序固定为：**先旋转和镜像，再按编辑页中所见方向裁切**。因此，应先把画面调到想要的方向，再在裁切编辑页中设定取景框。

### 一键安装 FFmpeg

普通预览不需要 FFmpeg。**视频和音频的 A/B 裁切导出、原码流音频导出需要 FFmpeg；`ffprobe` 可提供更丰富的媒体元数据。**

1. 在应用中点“裁切导出…”或“导出音频…”。若尚未安装 FFmpeg，点弹窗中的 **“安装 FFmpeg…”**；Terminal 会自动打开安装脚本。也可在 DMG 中手动双击随附的安装命令文件。
2. 脚本只在您主动运行后下载 `ffmpeg-static b6.1.1`，安装到 `~/Library/Application Support/Finder Media Preview/bin`。它不需要管理员权限，不修改 shell 配置，也不随应用附带任何 FFmpeg 或 ffprobe 二进制文件。
3. 默认下载地址是 `https://cdn.npmmirror.com/binaries/ffmpeg-static/b6.1.1`；只有连接或 HTTP 请求失败时，才会回退到固定的 GitHub 发布地址 `https://github.com/eugeneware/ffmpeg-static/releases/download/b6.1.1`。无论来自哪里，两个 gzip 文件都必须通过脚本内固定的 SHA-256 校验；校验失败会停止，不会改用其他来源。
4. 安装完成后完全退出并重新打开应用。脚本写入同目录的 `finder-media-preview-ffmpeg-static-manifest.txt`，记录本次来源和 SHA-256；第三方运行时为 GPL-3.0-or-later，完整来源、许可证链接和校验值见 DMG 内的 `THIRD_PARTY_NOTICES.md`。

若您已经自行安装 FFmpeg，可直接使用；安装完成后重新打开应用即可让它刷新可执行文件检查。

### 精确切点与画质

当前版本以**所选 A/B 时间准确**为优先，因此会重新编码导出的片段，不使用原码流直拷贝。视频导出为 H.264（CRF 18，高质量）和 AAC（192 kb/s）；音频导出为 AAC 256 kb/s M4A、MP3 VBR q2 或 16-bit PCM WAV。它们不是“原始码流逐字相同”的无损文件，但原始媒体绝不会被改动。

如果未来只在关键帧和音频包边界裁切，才可以用“直拷贝”得到原始码流无损结果；那种模式会受切点限制。本版本不暗中切换模式：保存面板会明确写出输出编码方式。

原始媒体始终保持不变。为了避免误覆盖，应用拒绝把结果写到原文件或已存在的目标文件。照片不支持 A/B 裁切导出。

### 导出进度、取消与完成判定

视频导出时，状态栏和进度条读取 FFmpeg 实际报告的输出时间进度，不是按计时器模拟的动画。进度从 `导出：0%` 开始，只有 FFmpeg 正常结束并确认导出成功后，进度条才会停在 `100%`，状态显示 **“已完成”**（随后可带文件名）。进行中可点“取消导出”；应用会停止 FFmpeg、清空并隐藏该次进度，不把未完成文件当作成功结果。取消、导出失败、关闭裁切编辑页或重新开始新的导出时，进度都会重置；原文件不会被改写。

裁切编辑页按播放器当前可见方向计算：会包含常规视频自身的方向信息，以及“逆90° / 顺90° / 镜像”的临时画面变换；FFmpeg 也会以同一顺序先变换再裁切，并将导出画面写成不再依赖旋转标签的方向。裁切导出会将输出像素宽高比设为方形像素。带有非标准旋转元数据、非方形像素（SAR）或特殊色度格式的素材，最终显示比例仍可能与某些播放器不同；重要素材建议先导出短片段确认画面方向和比例。

## 原码流导出音频

右侧“导出音频…”可从视频提取其第一条音频轨，也可导出音频文件本身。**它不会重编码**：在 FFmpeg 和输出容器支持的情况下，原始音频编码、声道布局、采样率与音频包内容均会保持不变。常见 MP4/MOV/M4A/AAC 来源建议导出为 M4A，MP3 来源为 MP3，WAV 来源为 WAV；其他来源默认使用 MKA。若目标容器不支持原始编码，应用会报错，不会暗中改为有损编码；可在保存面板中改用兼容的文件扩展名后重试。

没有设置有效 A、B 区间（包括只设置一个点）时，会导出整条音频。设置了有效 A、B 后，应用会先明确提示：无损直拷贝只能在音频编码包边界切割，无法保证任意毫秒都精确对齐。确认“按原码流导出”后才继续；因此所得片段的起止点或总时长可能与 A/B 显示值相差极短一段，但不会因而改变音频编码质量。没有可用音频轨的媒体会直接提示，不能导出。

## 视频与音频查看

- 视频画面支持触控板捏合缩放，范围为 1× 到 6×，不会缩得比原始适配画面更小。
- 缩放后可拖动画面，或用触控板滚动进行平移；双击画面或按 `0` 可恢复 1×。
- 左侧音量块支持单击、拖动、滚动；三指纵向触摸调整属于尽力支持，是否收到三指触摸事件仍受 macOS 的触控板手势设置影响。按“静音”后音量条会同步降至最小值；再次按会恢复到静音前的非零音量。静音状态下直接调整音量会自动取消静音。
- 音频文件使用系统解码器读取真实 PCM 振幅并显示波形，时间定位、A/B、循环、倍速、音量和静音逻辑与视频相同。

## 照片模式

打开照片时，应用会以正确比例完整显示大图，并在顶部显示格式、尺寸、像素、色彩空间以及可读取的拍摄参数。照片模式不显示播放控制、缩略图时间轴或音频波形。

## 快捷键设置

打开应用菜单 **Media Preview > 设置…**（默认 `⌘,`），点击任一快捷键按钮，再按下新的按键组合即可保存并立即生效。重复的快捷键不会覆盖原设置，`⌘S` 固定保留给 Finder 启动入口。“恢复默认设置”可一次恢复上表中的默认组合。作为标准 Mac 应用，`⌘Q` 始终可退出应用。

## 常见问题

**第一次启动被 macOS 拦截怎么办？** 参阅上方“安装”部分，使用 Control 点按应用后选择“打开”。请勿将本版本误认为已经过 Developer ID 签名或 Apple 公证。

**循环没有停在我选的范围内？** 请先确认 A 点在 B 点之前；无效或未完整设置的 A/B 点会自动使用整段文件循环。您也可以使用“清除”后重新设置 `I` 和 `O`。

**为什么“裁切导出…”提示需要 FFmpeg？** 视频和音频 A/B 裁切统一由 FFmpeg 执行；请按上方“一键安装 FFmpeg”完成安装后重试。若刚安装完仍未识别，请完全退出并重新打开应用。

**为什么这次不是无损直拷贝？** 本版本优先保证所选 A/B 时间准确，因此统一重新编码导出的片段；保存面板会显示视频或音频的实际输出编码方式。原文件不会被改动。

**“导出音频…”能保证 A/B 精确到每一毫秒吗？** 不能。该按钮优先保留原始音频码流，不做重编码，因此只能在编码包边界切割；确认提示后才会导出。若需要严格按 A/B 时间精确切点，请使用“裁切导出…”，并接受其重新编码方式。
